Project Codename: LAST TURN

Game Type:
Real-time multiplayer psychological risk game (2–6 players)

Platforms:
iOS & Android (mobile-first)

⸻

🧠 CORE CONCEPT

Design a real-player, turn-based multiplayer game inspired by Russian-roulette-style tension without any weapons, violence, or self-harm themes.

The game focuses on risk, bluffing, social pressure, and decision-making using an abstract “chamber” system.

Players take turns activating hidden slots. One slot per round triggers a Crash Event that causes penalties but does not eliminate players instantly.

⸻

🔁 CORE GAMEPLAY LOOP
	1.	Matchmaking (Private Room via Code)
	2.	Players join lobby (2–6 players)
	3.	Each round contains 6 hidden slots
	4.	One slot contains a Crash
	5.	Players take turns clockwise

On a Player’s Turn:
	•	Pull → Activate the next hidden slot
	•	Force → Choose another player to Pull (limited use)
	•	Pass → Skip turn using a limited token

Crash Event:
	•	Player loses 1 life or score
	•	Visual + sound feedback (screen shake, silence beat)
	•	Player stays in the game unless lives reach zero

⸻

🎯 WIN CONDITION
	•	Last player with remaining lives wins
OR
	•	Highest score after fixed rounds (optional mode)

⸻

🔥 GAME MODES

1️⃣ Classic Mode
	•	One Crash per round
	•	3 lives per player
	•	Last standing wins

2️⃣ Silent Mode
	•	No chat or voice
	•	Only timers and animations
	•	Focus on psychological pressure

3️⃣ Truth-or-Risk Mode
	•	Before pulling, player must answer a visible question
	•	Refusal or incorrect answer forces a Pull

4️⃣ Countdown Panic
	•	Turn timer decreases every round
	•	Timer expiry triggers auto-Pull

⸻

🧩 SOCIAL & PSYCHOLOGICAL FEATURES
	•	Real-time turn indicators (“Player X is thinking…”)
	•	Visible hesitation (delayed decisions increase tension)
	•	Revenge token: if forced into a Crash, player gets one guaranteed Force next round
	•	Endgame Twist: Final 2 players pull simultaneously

⸻
